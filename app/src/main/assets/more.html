Эллиптические кривые над полем вещественных чисел


Эллиптические кривые

Если обобщить, эллиптические кривые представляют собой кубические уравнения. Произвольное уравнение третьей степени выглядит следующим образом:

ax3 + bx2y + cxy 2 + dy3 + fx2 + gxy + hy2 + kx + iy + n = 0

Для того чтобы это уравнение задавало эллиптическую кривую оно должно быть невырожденным. В рамках написания выпускной квалификационной работы нет необходимости подробно разбирать это утверждение, но можно упомянуть, что одним из условий является то, что кривая должна состоять из неособых точек. Точка (x0, y0) кривой F (x, y) = 0 называется неособой, если в ней не равны нулю обе частные производные многочлена F (x, y).

(∂F( x 0 , y 0 )) / ∂x
≠ 0 и
(∂F( x 0 , y 0 )) / ∂y
≠ 0

Кривая называется неособой или гладкой, если все ее точки неособые, то есть в каждой точке этой кривой можно провести касательную:

(x - x 0 )
(∂F( x 0 , y 0 )) / ∂x
+ (y - y 0 )
(∂F( x 0 , y 0 )) / ∂y
= 0

Путем преобразований можно понять, что выражение кубической кривой, приведенное ранее сводится к достаточно простому виду.

y2 = x3 + ax + b

При этом возникает дополнительное условие, которое заключается в том, что существует хотя бы одна точка (x0, y0) с рациональными координатами, которая при подстановке в уравнение дает ноль. В дополнение к этому, правая сторона уравнения не должна иметь кратных корней, условие для этого можно сформулировать, прибегнув к понятию дискриминанта, которое для этого уравнения будет иметь следующий вид:

∆ = 4a3 + 27b2

Для того чтобы исключить особые кривые, которые не имеют для нас ценности, правая часть этого выражения не должна равняться нулю. Если значение становится равным нулю мы попадаем в особую ситуацию и кривая становится сингулярной. Приложение оповестит Вас об этом предупреждением внизу страницы.

Также, при обсуждении эллиптических кривых, нельзя не упомянуть такое важное явление, как 0. 0 – это бесконечно удаленная точка на графике эллиптической кривой, в рамках приложения она также может обозначаться как inf.


Сложение точек

В этом приложении Вам предоставлена возможность самостоятельно рассмотреть процедуру геометрического сложения, задав свои собственные произвольные параметры эллиптической кривой и координаты точек P и Q.

Опишем эту операцию. Тот факт, что точки эллиптической кривой – это абелева группа, позволяет нам утверждать, то P + Q = -R. Тогда, если провести прямую через точки P и Q, она также пройдет через точку R. Тогда, найдя обратную R, можно узнать сумму P + Q. На рисунке 8 представлен пример реализации операции геометрического сложения.

Для того чтобы такой способ был полным, необходимо определить, что будет происходить в нетривиальных случаях, тем самым охватив весь спектр вариантов сложения.

- Если P или Q равняется 0. Результат сложения в таком случае будет равняться одной из двух точек.

- Если P = - Q. Прямая в таком случае будет вертикальной и не иметь третьей точки пересечения с ЭК, в результате чего результатом выражения будет бесконечно удаленная точка 0.

- Если P = Q. В такой ситуации, проводимая кривая становится касательной к кривой, вторая точка, которую она пересечет будет R.

- P ≠ Q, но R нет. Этот пункт схож с предыдущим, в таком случае одна из точек становится касательной к кривой, а результатом сложения будет симметричная P или Q точка.

Для получения конкретных значений используется процедура алгебраического сложения по следующим формулам:

Для случая, когда P ≠ Q, нужно знать, что наклон прямой будет равняться:

m =
( y P - y Q ) / ( x P - x Q )

Тогда координаты точки R будут вычисляться так:

x R = m2 - x P - x Q

y R = y P + m( x R - x Q )

или

y R = y Q + m( x R - x Q )

Эти формулы также подходят для ситуаций, когда P или Q являются точками касания. В случае же, если P = Q наклон кривой будет вычисляться по-другому:

m =
(3 x P 2 - a) / 2 y P

Для координат формулы остаются неизменными.


Скалярное умножение

Для реализации криптографических алгоритмов или простого понимания их работы, необходимо понимать, как в рамках множества, задаваемого уравнением эллиптической кривой, выполняется вычисление кратных точек.

Скалярное умножение представляет собой выражение вида:

nP = P + P + ⋯ + P (n раз), где n - натуральное число.

Это приложение также предоставляет возможность визуализации операции умножения как графически, так и алгебраически, выдавая результат умножения в числовом эквиваленте.

Умножение осуществляется по алгоритму сложения-умножения.

Для того чтобы найти nP предпринимаются следующие шаги:

  1. Число n представляется в двоичном виде

    2. k = b t b t-1 ... b 0 , b i ∈ {0,1}

  2. Вычисляются точки 2P,4P,…,2tP
  3. Вычисляется сумма точек 2iP, для которых b i = 1, i = 0, … , t, то есть вычисляется сумма точек, соответствующих значащим битам в двоичном представлении числа n.

Эллиптические кривые над конечным полем Fp

Конечное поле – это множество с конечным числом элементов. Fp – конечное поле характеристики p, где p – простое число. Множество всех целых чисел по модулю p состоит из всех целых чисел от 0 до p-1. Здесь также необходимо применение модульной арифметики, которая привносит некоторые сложности в процедуру деления.

Нужно учитывать, что x/y = x*y-1, что позволяет нам заменить процедуру деления простым умножением на число, обратное числу в знаменателе. Для вычисления обратного числа будет реализован расширенный алгоритм Евклида, который обладает достаточно небольшой сложностью.

Если рассматривать эллиптическую кривую над конечным полем, формулы практически не подвергаются изменениям, но все равно есть необходимость уточнить несколько моментов.

В уравнение кривой дбавляется новая характеристика и оно приобретает несколько иной вид.

y2 ≡ x3 + ax + b(mod p)

Условие дискриминанта также ограничивается значением p:

[4a3+27b2](mod p) ≠ 0

Если подытожить все вместе, формула предстает перед нами в следующем виде:

{(x,y)∈( F p )2 | y2 ≡ x3 + ax + b(mod p), 4a3 + 27b2 ≢ 0(mod p)} ∪ {0}

Поскольку мы ограничены конечным полем, график эллиптической кривой отображается в виде набора отдельных точек, симметричных относительно оси x. Помимо этого, из-за того, что мы находим над полем вещественных чисел, образованных некоторым простым числом, график не может содержать отрицательных значений.

Алгоритм поиска точек при рассмотрении кривой над конечным полем, имеет следующие шаги:

  1. x3 + ax +b (mod p) для всех 0 ≤ x < p
  2. y2(mod p) для всех 0 ≤ y < p
  3. (x, y): y2 ≡ x3 + ax + b (mod p), что означает необходимость выбора таких точек, которые удовлетворяют условиям
  4. Добавить к списку точек бесконечно удаленную точку 0.

Сложение точек

Для построения алгоритма, реализующего операцию сложения точек кривой над конечным полем, будут использоваться следующие формулы:

Для случая, когда P ≠ Q:

m = ( y P - y Q )( x P - x Q )-1(mod p)

Тогда координаты точки R будут вычисляться так:

x R = (m2 - x P - y Q )(mod p)

y R = [ y P + m( x R - x Q )](mod p) = [ y Q + m( x R - x Q )](mod p)

В случае же, если P = Q наклон кривой будет вычисляться следующим образом:

m = (3 x P 2 - a)(2 y P )-1(mod p)

Формулы выше справедливы для любого значения p, представленного простым числом, за исключением 2 и 3, которые являются особенными случаями как над полем, так и над полем вещественных чисел.


Порядки группы и подгруппы

Порядком группы является количество точек эллиптической кривой, определенное простым модулем p.

Ранее был приведен алгоритм умножении точек для кривых над полем вещественных чисел, при рассмотрении этой же операции над конечным полем возникает несколько важных нюансов, на которые следует обратить внимание при реализации. Если взять какую-либо точку и провести над ней операцию умножения, в конечном итоге можно заметить, что получаемые значения повторяются с некоторой периодичностью. Эта периодичность и задает порядок подгруппы, порождаемый некоторой точкой, что делает эту точку базовой.

Порядком n точки P на эллиптической кривой называется наименьшее натуральное число, такое что nP = 0. У этого числа есть важное свойство – оно является делителем для порядка группы. Это приложение также осуществляет поиск группы точек эллиптической кривой и подгруппы, порождаемой точкой P, координаты которой задает сам пользователь.

Алгоритм вычисления порядка точки эллиптической кривой: берется порядок эллиптической кривой N, для него находятся все делители, после для каждого из них вычисляется nP и такое наименьшее n, при котором получается 0 и есть порядок подгруппы

Существую также более быстрые алгоритмы поиска порядка группы, например, алгоритм, использующий теорему Хассе.


Базовая точка и дискретный логарифм

Понятие базовой точки очень важно для полного понимания криптографических алгоритмов на эллиптических кривых, но стоит уточнить, что в моем приложении пользователю предоставлена свобода действий в этой области. Существует алгоритм подбора точки, но обычно при реализации какого-либо алгоритма шифрования используются уже готовые кривые с доказанной криптостойкостью, для которой найдена хорошая базовая точка с большим и надежным порядком. То есть, для подобных кривых сначала выбирается достаточный порядок подгруппы, а уже после подбирается точка, которая порождает эту подгруппу. К примеру, в разделе приложения с примером шифрования на кривых с большими числами пользователю на выбор будет представлено некоторое количество кривых, таких, как p-256.

Говоря о задаче дискретного логарифмирования, пусть E – эллиптическая кривая, определенная над Fp, P – точка, принадлежащая E. Тогда задача дискретного логарифмирования на Е (с основанием p) – это задача нахождения для Q ϵ Е целого числа m ϵ Z, такого, что mP = Q. Криптография на эллиптических кривых интересна тем, что данная задача решается гораздо труднее, чем для других криптографических алгоритмов, что позволяет при том же количестве бит получить более высокий уровень стойкости ко взломам.


Эллиптические кривые над конечным полем Fp

Для начала определим, что в общем случае для реализации алгоритмов шифрования-дешифрования, необходимы следующие данные:

  • Сама эллиптическая кривая Еp (a, b) и ее порядок |Ep (a,b)| = N
  • координаты точки G, являющейся базовой
  • порядок подгруппы, определяемый точкой G
  • кофактор подгруппы – h = N/n

В итоге мы получаем следующий набор значений: (p, a, b, G, n, h).

Для вычисления пары открытый-закрытый ключ есть следующие правила:

  • Закрытым ключом d будет случайное число, выбираемое из диапазона от 1 до n-1, где n – простое число, являющееся порядком подгруппы, порожденным базовой точкой G
  • открытый ключ – это точка H = dG, где G-базовая точка.

Значения H и G всегда известны. Для того чтобы найти d и тем самым взломать алгоритм необходимо решить уравнение H = dG, что является решением задачи дискретного логарифмирования и представляется нетривиальной задачей.

В приложении Вы имеете возможность шифрования строковых значений посредством использования произвольных значений a, b, d и так далее. Сам реализованный алгоритм содержит следующие шаги:

  1. Вами задается закрытый ключ d и координаты базовой точки P.
  2. Вычисляется кратная точка Q = dP.
  3. Считывается символ сообщения и представляется в виде числа.
  4. Выбирается случайное число k в диапазоне от 1 до n-1, где n – порядок подгруппы.
  5. Считается кратная точка Pk(xq, yq) = kP.
  6. Считается кратная точка Qk(xq, yq) = kQ.
  7. Шифротекст: c = (t*xq)mod p.

Важно предупредить, что при использовании произвольных значений не будет обеспечиваться достаточный уровень надежности шифрования, но данная выпускная квалификационная работа призвана в первую очередь предоставить пользователям возможность интерактивного изучения криптографических алгоритмов.

Процедура дешифрования происходит в следующем порядке:

  1. Получение входных значений
  2. Вычисление точки D: D(xd, yd) = dPk.
  3. Исходное сообщение, t = (c*xd-1)mod p, где xd-1 обратное число к xd по модулю p
  4. t здесь – это числовое представление числа по заданному словарю.
