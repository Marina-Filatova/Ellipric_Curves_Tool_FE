# Elliptic Curve Cryptography Tool

Мобильное приложение для интерактивной демонстрации и изучения эллиптических кривых и криптографии на их основе.

## О проекте

Данный репозиторий содержит выпускную квалификационную работу (дипломный проект), выполненную в **Нижегородском государственном техническом университете им. Р. Е. Алексеева**.

**Тема:** Разработка мобильного приложения для демонстрации работы с эллиптическими кривыми  

Приложение создано как образовательный инструмент для студентов, изучающих курс «Теоретико-числовые методы криптографии», а также для всех, кто интересуется математическими основами современной криптографии.

## Возможности приложения

### 📈 Построение графиков эллиптических кривых
- Над полем **вещественных чисел** (ℝ) с интерактивной визуализацией
- Над **конечным полем** (𝔽ₚ) с отображением дискретного набора точек

### ➕ Операции над точками кривой
- **Сложение точек** — геометрическая и алгебраическая демонстрация
- **Скалярное умножение** — с пошаговой визуализацией
- Поддержка всех особых случаев (P = Q, P = −Q, точка в бесконечности)

### 🔐 Криптография на эллиптических кривых
- **Шифрование и дешифрование** текстовых сообщений с возможностью задания произвольных параметров кривой
- Поддержка русского и английского алфавитов
- **Шифрование на реальных кривых** (P-256, Curve25519 и др.) через библиотеку OpenPGP.js

### 🧭 Удобный интерфейс
- Боковое меню для навигации между разделами
- Модальные окна с пояснениями для сложных параметров
- Динамическое обновление графиков при изменении входных данных
- Предупреждения о сингулярных кривых и составных модулях

## Как запустить

1. Склонируйте репозиторий:
   ```bash

   ```
2. Откройте проект в Android Studio Hedgehog или новее.

3. Синхронизируйте Gradle и запустите на эмуляторе или устройстве с Android.
